# 0006. 폐쇄망에서 동작하는 지도

**상황** 현장 장비 관제는 인터넷이 없는 환경에서 돈다. 온라인 지도 API(구글·카카오 등)를 쓸 수 없다.

**결정**
- 지도 라이브러리(Leaflet)를 저장소에 포함한다. 화면이 외부 URL을 하나도 요청하지 않는다.
- 지도 타일은 MBTiles(SQLite 파일 하나)로 배포하고 서버가 `/tiles/{z}/{x}/{y}.png`로 꺼내 준다.
  MBTiles는 TMS 좌표계라 y를 뒤집는다.
- 타일이 없을 때도 위치 관계를 볼 수 있도록 위경도 격자를 직접 그린다.

**수신 프로토콜** `$POS,<id>,<lat>,<lon>,<km/h>,<deg>*<XOR 체크섬>` NMEA 스타일. 시리얼·UDP·TCP가 같은 파서를 쓴다.
TCP는 줄 단위로 읽어 프레임이 나뉘어 와도 안전하고, 시리얼은 블로킹 I/O라 별도 스레드에서 읽는다.
체크섬·범위 오류 프레임은 버리고 건수를 화면에 표시한다.

**검증** `tests/test_field.py` (체크섬, 범위, TCP 부분 수신, 통신 두절·복구, MBTiles y 변환).
