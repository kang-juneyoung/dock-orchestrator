# 0004. 고객사마다 다른 WMS·TMS는 어댑터가 흡수한다

**상황** A사는 팔레트 단위 JSON에 도크를 `D-05`로, B사는 박스 단위 JSON에 `Gate 5`로 쓴다. 배차는 CSV로 온다.
고객사가 늘 때마다 코어 로직을 고치면 회귀 위험이 커진다.

**결정** 형식별 파서를 레지스트리에 등록하고(`@wms_adapter("json_v2")`), 고객사 설정이 어떤 어댑터를 쓸지 고른다.
어댑터는 `NormalizedOrder` / `NormalizedDispatch`만 만들어낸다. 도크 번호 표기와 박스→팔레트 환산도 어댑터 책임이다.

**결과** 새 고객사 = 어댑터 파일 하나 + 테스트 하나. 형식 오류는 422로 돌려주고 코어까지 가지 않는다.
실서비스에서는 고객사가 우리 형식에 맞추기 어려운 경우가 많으므로, 이 계층이 영업상 경쟁력이 된다.
